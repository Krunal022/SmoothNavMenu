# 🚀 Smooth Animated Navigation Menu with Hamburger Toggle

A sleek, modern navigation menu built with **GSAP** featuring a smooth sliding underline animation. On smaller screens, a hamburger icon toggles the menu items with a smooth appear/disappear effect.

---

## ✨ Features

- Smooth sliding underline animation on menu items  
- Responsive design with hamburger toggle for mobile  
- Smooth show/hide animation for menu on hamburger click  
- Built with HTML, CSS, and GSAP  
- Easy to customize and integrate
